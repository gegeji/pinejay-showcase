# Pinejay showcase

A short tour of [Pinejay](https://gegeji.github.io/), a self-hosted agent built on [NanoClaw](https://github.com/qwibitai/nanoclaw) that I use mostly through Telegram.

The pages replay scripted conversations: a course with inline buttons, weather alerts, Chronicle (a record of what was said and who said it), widgets drawn inside replies, and how the project is built and maintained by agents.

All data on this site is fictional. There is no backend and no model behind it.

The site is plain HTML, CSS and JavaScript with no build step. Open `index.html` or serve the folder with any static server. Copy and scripts for English, Simplified Chinese, Traditional Chinese (Hong Kong) and Japanese live in `content.js`.

Pinejay itself is a personal project. If you want to contribute to the agent, please contribute to [NanoClaw](https://github.com/qwibitai/nanoclaw) upstream.
